# Zuppa — Angular Frontend

This is the frontend of project **Zuppa** (built with Angular 21). For detailed documentation, architecture, Docker setup, and API reference, see the backend repository:

 **[zuppa-recipe-book-backend](https://github.com/raczb/zuppa-recipe-book-backend)**

---

## Getting Started (Local Development)

1. **Clone the repository**
   ```bash
   git clone https://github.com/raczb/zuppa-recipe-book-frontend.git
   cd zuppa-recipe-book-frontend
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm start
   ```
   The application will be available at `http://localhost:4200` (expecting the Zuppa backend API at `http://localhost:8080`).
